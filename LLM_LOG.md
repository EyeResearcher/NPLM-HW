I used ChatGPT 5.6 Sol for this assignment. I asked it to review the code base and instructions and formulate an architectural plan to be implemented later. Then I prompted it to create subagent contracts for each aspect of the architecture, which essentially lined up with each planned module. I specified that the contracts must include the intended output of the main module functions as well as the expected objects returned by other modules of use to a given module. Finally, I asked it to generate one subagent per contract to implement. 

I found that the agents ignored my triple quotes comments at the top of each of module in favor of greedily and strictly carrying out the contracts. This included ignoring the dual funuctionality of the download module to handle both hugging face dataset downloads and url downloads because I had already stated I intended to use a hugging face dataset. 

One thing I always notice with LLM-generated code is the sheer number of lines dedicated to variable validation. This can be useful but quickly becomes redundant when high level functions validate the structure and content of objects and data structures upstream of low level function calls. This rarely if ever affects the functionality of the code, but it almost always significantly impacts the readability of it, at least for me.
